# Catalog — каталог решений сервиса

Папка `catalog/` в корне целевого проекта: `index.md` (генерируется; строка на единицу: маршрут · фраза ·
код) и карточки `<id>.md` (та же строка + код + раздел + ссылки). Формат — `../../resources/catalog/catalog-format.md`,
пример — `../../resources/catalog/catalog.example/`, скрипт — `../../resources/catalog/extract-catalog.mjs`
(пути — от папки этого скилла).

Принципы: код первичен, каталог указывает; не индексировать всё; опыт (грабли, причины отказов) в каталог
не пишется — он живёт в коде, гейте и registry.

## Режимы

### Бутстрап (в проекте нет `catalog/`)
1. Прочитай `catalog-format.md`.
2. `node extract-catalog.mjs <repoRoot> --out-dir <repoRoot>/catalog` (Next.js pages-router; другие
   фреймворки — карточки по формату вручную, начиная с архетипов страниц и источников данных). Скрипт
   создаёт карточки основного списка: архетипы с реальными страницами, кастомные блоки, конвенции,
   компоненты с ≥ 3 использованиями, внешние источники; остальных кандидатов отдаёт в `--json`.
3. Квалифицируй карточки по коду: замени «— уточнить» на одну фразу-задачу; у источников данных —
   ограничения (кэш, токен, покрытие); у конвенций — правило одной фразой + пример-файл. Назначение
   страницы не читается из кода — **спроси пользователя**, несколько единиц одним вопросом.
4. `--index`, `--lint`; покажи итог: сколько карточек по разделам, что осталось уточнить.

### Перенос каталога старого формата (в корне лежит `catalog.md`, папки `catalog/` нет)
Одиночный файл — черновик бета-версии 0.6.0. `node extract-catalog.mjs --from-legacy catalog.md
--out-dir catalog/` → каждая строка `- **id** — …` становится карточкой с текстом verbatim, раздел — по
заголовку исходника. Покажи `index.md`, спроси, убирать ли старый файл (скрипт его не удаляет).

### Обновление (репо изменился)
`extract-catalog.mjs <repoRoot> --out-dir /tmp/catalog.new` → сравни с `catalog/`: новые единицы — добавь
карточками (с «— уточнить» или сразу фразой по коду); карточки, чей код исчез (`--lint`: «код не найден») —
предложи удалить. Фразы пользователя не перезаписывай. `--index`.

### Разбор (по просьбе: «убери X», «уточни фразу у Y», «каталог разросся»)
Удалить единицу = удалить `catalog/<id>.md` + `--index`. Уточнить = править строку карточки + `--index`.
Покажи дифф индекса до записи; ничего не удаляй молча.

## Чего не делать
- Не писать в каталог грабли, причины отказов и прочий опыт сборок — только «что есть и где».
- Не квалифицировать назначение страниц догадкой — вопрос дешевле ошибочной строки.
- Не превращать строку в абзац (`--lint`).

## Связь
- `create` читает `index.md` и карточки выбранных единиц; построив новое — добавляет карточку.
- `synthesize-profile` описывает вкус сервиса; каталог — что собрано и из чего. Разные файлы, разный ритм.
